# Room3D - walkable bedroom for the Crayon Engine

Everything (models, textures, arrangement, collision boxes) is generated by Python:

    pip install pillow numpy
    python tools/generate_room.py

Open the folder with Crayon (entry point `main.lua`).

* Desktop: click to capture the mouse, mouse look, WASD walk, SHIFT run, arrows also look, ESC releases the mouse, H hides help.
* Touch: drag on the left half to walk, right half to look.
* Collision: walls, desk, chair, bookshelf, bed and speaker (boxes are written into `main.lua` by the generator).

Objects: desk with CRT PC, lamp, fan, mug, pen holder and books; swivel chair; bookshelf with books and crates;
window with mullions, curtain and rod; air conditioner; bed with under-bed boxes and speaker; speaker; wall calendar;
slippers; wooden floor; warm sunset light + sunlight patch on the floor.
If textures look upside-down set `FLIP_V = True` in the generator and re-run.
