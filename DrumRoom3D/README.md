# DrumRoom3D - rehearsal room with a playable yellow drum kit (Crayon Engine)

Everything (models, textures, drum sounds, kit pick-shapes, collision boxes) is generated by Python:

    pip install pillow numpy
    python tools/generate_all.py        # already run once; re-run after editing tools/*.py

Open the folder with Crayon (entry point `main.lua`).

* Click / tap a drum or cymbal to play it. Snare rim = rim-shot, ride bell = bell, hi-hat pedal toggles open/closed.
* Desktop: hold RIGHT mouse + move to look, WASD walk, SHIFT run, arrows look, T auto-beat, H hides help.
  Keys: SPACE kick, J snare, B rim, U/I/O toms, K hi-hat, M hat open/close, L crash, P ride, N ride bell.
* Touch: tap drums, left half walks, right half looks.
* If textures look upside-down set `FLIP_V = True` in `tools/meshlib.py` and regenerate.
* `tools/preview.py` is an optional software renderer for checking assets without the engine.
